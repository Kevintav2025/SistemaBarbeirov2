# 💈 Sistema Barbeiro v2

Este é um sistema web desenvolvido para a gestão e modernização de barbearias. A aplicação foi criada para facilitar o agendamento de horários, controle de serviços prestados, gerenciamento de clientes e acompanhamento do faturamento do estabelecimento.

## 🚀 Demonstração

O projeto está hospedado e pode ser acessado diretamente pelo navegador através do link:
👉 [Acessar o Sistema Barbeiro v2](https://kevintav2025.github.io/SistemaBarbeirov2/)

---

## 💻 Telas Integradas

O sistema é dividido em módulos projetados para otimizar o atendimento e a administração da barbearia:

* **Página Inicial (`index.html`):** Painel principal com os agendamentos do dia, avisos e atalhos rápidos.
* **Autenticação (`login.html`):** Tela de login para barbeiros, administradores e recepção.
* **Agendamento de Horários:** Interface para selecionar barbeiro, serviço, data e horário disponíveis.
* **Cadastro de Clientes:** Painel para registrar dados de contato e histórico de visitas dos clientes.
* **Controle de Serviços e Preços:** Tela de configuração para listar os serviços oferecidos (corte, barba, pigmentação, etc.) e seus respectivos valores.
* **Fluxo de Caixa / Relatórios:** Área dedicada ao fechamento de caixa diário e comissões dos profissionais.

*(Nota: Caso os arquivos HTML no seu VS Code tenham nomes específicos como `telaAgendamento.html` ou `barbeiros.html`, lembre-se de ajustar esta lista diretamente no arquivo).*

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação dos formulários de marcação de horário, tabelas e vitrine de serviços.
* **CSS3:** Estilização moderna, responsiva e alinhada com a identidade visual de barbearias clássicas ou modernas.
* **C# / JavaScript:** Lógica para validação de horários (evitando choques na agenda), cálculos de comissão e controle do sistema.
